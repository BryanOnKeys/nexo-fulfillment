# Reportar un problema de seguridad

Para comunicar una vulnerabilidad utiliza un aviso privado en la sección Security del repositorio, cuando esté habilitada. Evita publicar tokens, datos privados o instrucciones con credenciales en un issue público.

El entorno local utiliza datos ficticios y secretos generados durante la instalación. No está destinado a almacenar datos reales sin completar los controles del entorno productivo descritos en la documentación.
